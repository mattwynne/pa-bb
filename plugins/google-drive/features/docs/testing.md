## Normal commands

- `npm run test:docs:fast`: enforced no-SDK/SQLite/process/network boundary;
  actual models, use cases, selection, projection, witnesses and lifecycle policy.
- `npm run test:docs:adapters`: real HTTP adapter/decoder with injected I/O,
  independently expected requests, failures and privacy sentinels.
- `npm run test:docs:integration`: actual SQLite/native registration, ownership,
  schema, migration, reopen, tamper, capacity, atomic publication and process
  channel checks. The SDK host always has a real file database.
- `npm run test:docs`: one current Cucumber execution and independent intake,
  including fixed mandatory native/HTTP/SQLite companions. No saved summary is
  treated as a fresh pass. Package `test` runs this once, not inside each family.
