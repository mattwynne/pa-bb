# README screenshots

Captured from a disposable BB 0.45.0 installation with Obsidian 0.3.1. The image is cropped to BB's expanded plugin settings panel. The old Calendar screenshot was removed when Google Workspace replaced that plugin.

The installed plugin renders its actual UI, but browser-intercepted status responses supply the example vault. The “Project notes” vault is fictional. No Google, Apple or other provider account was connected, and no real notes, credentials or private deployment details appear.

These images illustrate settings, not successful sign-in, tool calls or cloud delivery. To refresh them, use another isolated BB installation with generated data; never publish screenshots of personal account settings without reviewing their contents.
