# README screenshots

Captured from a disposable BB 0.45.0 installation with Google Calendar 0.1.1 and Obsidian 0.3.1. Images are cropped to BB's expanded plugin settings panel.

The installed plugins render their actual UI, but browser-intercepted status responses supply the example accounts and vault. The `example.com` addresses and “Project notes” vault are fictional. No Google, Apple or other provider account was connected, and no real notes, credentials or private deployment details appear.

These images illustrate settings, not successful sign-in, tool calls or cloud delivery. To refresh them, use another isolated BB installation with generated data; never publish screenshots of personal account settings without reviewing their contents.
